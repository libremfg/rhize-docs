Release notes for version 3.3.2 of the Rhize application.

*Release date:* 2026-08-21

## Changes by service

The following sections document the changes this release brings to each service.

### Admin UI

#### Add

- Add `OperationalLocation` class-inherited property display
- Add `OperationsEventDefinition` class-inherited property display
- Add `PhysicalAsset` class-inherited property display

#### Change

- Change inherited property tables: fix bulk-select rowId and remove orphaned queries

#### Fix

- Fix Gate Mapbox map rendering on access token presence
- Fix Person property inheritance display and Save dirty-state
- Fix OIDC behavior

### BAAS

#### Add

- graphql/admin: add `cdcState` query for CDC tracker observability
- alpha: add read-only replica mode for read replicas

#### Change

- chore(deps): change gqlgen to v0.17.93 to continue sandbox access

#### Fix

- worker: fix CDC-pinned orphaned transactions
- worker/cdc: fix reset stranded pending events when WAL is trimmed past `seenIndex`
