Release notes for version 4.5.1 of the Rhize application.


**Highlights:**

- New workflow editor experience with associated workflow engine improvements (2-3x improvement under concurrent load) built on Restate 1.7
- Nested mutations
- Further support for generic OIDC providers
- Many Admin UI and BaaS console fixes
- Access to environment variables for workflow steps
- Event source configuration from Kubernetes environment
- Improvements to for alignment with the ISA-95 standard


_Release date:_
14 Oct 2026

## Upgrade

Upgrade to 4.4.1 requires the following:

-To enable the new workflow engine, the schema must be upgraded and the new workflow editor in Admin UI must be enabled through the `APP_ENABLE_WORKFLOW_EDITOR` feature flag environment variable.
- ⚠️ To deploy the updated schema but remain on the old workflow engine, you must modify the `createAndRunBpmn` endpoints in the schema to use the old workflow Restate function. 
- Check if data migration is required for some ISA95 relationships, which have been updated to better align with the standard 

Then follow the [Upgrade instructions](/deploy/upgrade).
