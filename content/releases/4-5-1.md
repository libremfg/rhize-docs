## Upgrade

Upgrade to 4.4.1 requires the following:

-To enable the new workflow engine, the schema must be upgraded and the new workflow editor in Admin UI must be enabled through the APP_ENABLE_WORKFLOW_EDITOR feature flag envVar setting.
- If you wish to deploy the updated schema but remain on the old workflow engine, the createAndRunBpmn endpoints in the schema will need to be modified to use the old workflow Restate function ￼ 
- Check if data migration is required for some ISA95 relationships that have been updated to better align with the standard 

Then follow the [Upgrade instructions](/deploy/upgrade).
